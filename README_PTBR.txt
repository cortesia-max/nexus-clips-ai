NEXUS CLIPS AI — versão inicial

PUBLICAÇÃO NO RENDER
1. Envie os arquivos e pastas deste ZIP para um repositório GitHub (extraia o ZIP antes de enviar).
2. No Render, escolha New > Web Service e conecte o repositório.
3. O Render detectará o Dockerfile. Use o plano disponível na sua conta e clique em Deploy.
4. Abra o endereço publicado.

IMPORTANTE
- Esta versão gera até cinco cortes sequenciais do vídeo enviado, em formato vertical 9:16.
- Ainda NÃO identifica momentos virais com IA, não busca/captura lives e não publica no TikTok.
- O processamento depende de FFmpeg instalado no servidor (incluído no Dockerfile).
- Use somente vídeos próprios ou cujo uso você tenha autorização. O upload pode consumir espaço e memória do servidor.
